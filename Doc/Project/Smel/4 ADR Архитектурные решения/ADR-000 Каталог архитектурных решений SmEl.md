# 1. Назначение

Настоящий документ является каталогом архитектурных решений проекта SmEl.

Каталог фиксирует состав архитектурных решений, их последовательность и текущее состояние.

# 2. Область применения

Каталог применяется ко всем архитектурным решениям серии ADR проекта SmEl.

Статус конкретного ADR определяется последней записью его истории статусов.

# 4. Правила

1. ADR является основным форматом фиксации архитектурных решений SmEl.
    
2. Каждый ADR имеет уникальный идентификатор.
    
3. Каждый ADR создаётся на основании TPL-007.
    
4. История статусов сохраняется накопительно.
    
5. Текущим считается последний статус документа.
    
6. Принятые архитектурные решения являются базой для последующих решений.
    
7. Новое ADR не должно дублировать ответственность ранее принятого решения без архитектурного основания.
    
8. Изменение принятого решения выполняется посредством новой редакции либо нового связанного ADR.
    
9. Открытые технические решения не должны фиксироваться без достаточного архитектурного основания.
    
10. Каталог ADR отражает актуальное состояние архитектурного пакета.
